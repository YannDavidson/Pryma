# Security

PRYMA is pre-alpha. No release is approved for sensitive communications. The included UI prototype does not provide remote messaging or end-to-end encryption.

Do not put credentials, private keys, recovery secrets, real conversations, or user identifiers in issues, fixtures or commits. Use synthetic test data.

For a vulnerability, use GitHub private vulnerability reporting if enabled. Otherwise contact the repository owner through an established private channel; do not post exploit details or sensitive data publicly. A dedicated reporting channel must be established before inviting alpha users.

Production release gates are recorded in docs/decisions/0001-messaging-protocol.md and docs/ROADMAP.md. Security claims must match implementation and independent review evidence.
